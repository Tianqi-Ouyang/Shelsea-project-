1 Overview

This report compares patients with hepatorenal syndrome–acute kidney injury (HRS-AKI) treated with terlipressin against a historical cohort treated with off-label vasoconstrictors (midodrine/octreotide, norepinephrine, or vasopressin).

Item Definition
Terlipressin cohort HARMONY multi-center registry (group = "terli")
Off-label cohort Prior multi-center HRS registry, restricted to final_type_of_aki == 2 and hrs_vasoconstrictor == 1 (group = "hrs")
Treatment response hrs_responders_cat_2: 1 = complete or partial response, 0 = no response
Follow-up time time_90days — days from treatment initiation, truncated at 90
90-day status status_90days — 0 = alive/censored, 1 = death, 2 = liver transplant (competing event)
Matching 1:1 nearest-neighbour propensity score, caliper 0.2 SD
NoteHow to read this report

All code is folded by default — use Show code on any block, or the </> Code menu at the top right to expand everything. Sections 5 and 6 contain the creatinine–response tables and the new 90-day survival analyses.

create_first_nonzero_value <- function(data, original_variable, new_variable) {
  # Build the expected column names
  day_vars <- paste0(original_variable, "_day", 1:13)

  # Keep only those that exist in the dataset
  valid_day_vars <- day_vars[day_vars %in% names(data)]

  # Apply logic and keep only subjectid + new_variable
  data %>%
    rowwise() %>%
    mutate(
      !!sym(new_variable) := {
        values <- c_across(all_of(valid_day_vars))
        first_valid <- values[!is.na(values) & values != 0]
        if (length(first_valid) > 0) first_valid[1] else NA
      }
    ) %>%
    ungroup() %>%
    select(subjectid, all_of(new_variable))  # keep subjectid + new var
}

# Responders by creatinine band, with N for each cohort and overall.
resp_by_cat <- function(data, catvar) {
  cat_sym <- rlang::sym(catvar)

  by_grp <- data %>%
    group_by(!!cat_sym, group) %>%
    summarise(N      = n(),
              n_resp = sum(hrs_responders_cat_2 == 1, na.rm = TRUE),
              n_eval = sum(!is.na(hrs_responders_cat_2)),
              .groups = "drop") %>%
    tidyr::pivot_wider(id_cols = !!cat_sym, names_from = group,
                       values_from = c(N, n_resp, n_eval), values_fill = 0)

  overall <- data %>%
    group_by(!!cat_sym) %>%
    summarise(N_all      = n(),
              n_resp_all = sum(hrs_responders_cat_2 == 1, na.rm = TRUE),
              n_eval_all = sum(!is.na(hrs_responders_cat_2)),
              .groups = "drop")

  by_grp %>%
    left_join(overall, by = catvar) %>%
    arrange(!!cat_sym) %>%
    mutate(
      resp_hrs   = sprintf("%d (%.1f)", n_resp_hrs,   100 * n_resp_hrs   / pmax(n_eval_hrs, 1)),
      resp_terli = sprintf("%d (%.1f)", n_resp_terli, 100 * n_resp_terli / pmax(n_eval_terli, 1)),
      resp_all   = sprintf("%d (%.1f)", n_resp_all,   100 * n_resp_all   / pmax(n_eval_all, 1))
    ) %>%
    select(band = !!cat_sym,
           N_hrs, resp_hrs, N_terli, resp_terli, N_all, resp_all)
}

# Overview {#sec-overview}

This report compares patients with hepatorenal syndrome–acute kidney injury (HRS-AKI)
treated with **terlipressin** against a historical cohort treated with **off-label
vasoconstrictors** (midodrine/octreotide, norepinephrine, or vasopressin).

| Item | Definition |
|:-----|:-----------|
| Terlipressin cohort | HARMONY multi-center registry (`group = "terli"`) |
| Off-label cohort | Prior multi-center HRS registry, restricted to `final_type_of_aki == 2` and `hrs_vasoconstrictor == 1` (`group = "hrs"`) |
| Treatment response | `hrs_responders_cat_2`: **1** = complete or partial response, **0** = no response |
| Follow-up time | `time_90days` — days from treatment initiation, truncated at 90 |
| 90-day status | `status_90days` — **0** = alive/censored, **1** = death, **2** = liver transplant (competing event) |
| Matching | 1:1 nearest-neighbour propensity score, caliper 0.2 SD |

resp_by_cat <- function(data, catvar) {
  cat_sym <- rlang::sym(catvar)

  by_grp <- data %>%
    group_by(!!cat_sym, group) %>%
    summarise(N      = n(),
              n_resp = sum(hrs_responders_cat_2 == 1, na.rm = TRUE),
              n_eval = sum(!is.na(hrs_responders_cat_2)),
              .groups = "drop") %>%
    tidyr::pivot_wider(id_cols = !!cat_sym, names_from = group,
                       values_from = c(N, n_resp, n_eval), values_fill = 0)

  overall <- data %>%
    group_by(!!cat_sym) %>%
    summarise(N_all      = n(),
              n_resp_all = sum(hrs_responders_cat_2 == 1, na.rm = TRUE),
              n_eval_all = sum(!is.na(hrs_responders_cat_2)),
              .groups = "drop")

  by_grp %>%
    left_join(overall, by = catvar) %>%
    arrange(!!cat_sym) %>%
    mutate(
      resp_hrs   = sprintf("%d (%.1f)", n_resp_hrs,   100 * n_resp_hrs   / pmax(n_eval_hrs, 1)),
      resp_terli = sprintf("%d (%.1f)", n_resp_terli, 100 * n_resp_terli / pmax(n_eval_terli, 1)),
      resp_all   = sprintf("%d (%.1f)", n_resp_all,   100 * n_resp_all   / pmax(n_eval_all, 1))
    ) %>%
    select(band = !!cat_sym,
           N_hrs, resp_hrs, N_terli, resp_terli, N_all, resp_all)
}
